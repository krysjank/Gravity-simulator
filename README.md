# Gravity-simulator
Gravity simulator that defines your fantasy...
Welcome to Gravity simulator!!!
-------------------------------------------------------------------------
You can:
--> Build your custom gravity simulations.
--> Perform gravity assists.
--> See how bodies in space affect each other.
--> Place the bodies anywhere you want.
-------------------------------------------------------------------------

The manual is included in the simulation, simply follow the instructions on the screen.

For demo purposes, the online version of this programm is created in scratch(containing the same functionalities) can be found at this link https://scratch.mit.edu/projects/1376605963/
